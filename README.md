# nodered-project
Smart home temperature and humidity control system
The purpose of this project is to develop a Smart home temperature and humidity control system using Node-RED and MQTT communication.

The application is meant to monitor temperature and humidity levels within a smart home environment and automatically control an air conditioner and humidifier based on information gathered.

The system would use simulated sensor readings in order to demonstrate automatic device control and to generate alerts when environmental conditions fall outside the specified ranges.

The technologies used will be Node-RED, MQTT, and JavaScript,
